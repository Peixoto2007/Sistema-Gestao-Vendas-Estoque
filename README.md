# Sistema de Gestão de Vendas e Estoque

## Descrição
Sistema desenvolvido em Java com POO para controle de vendas e estoque. Permite cadastrar produtos, registrar vendas e clientes e controlar entrada/saída de estoque.

## Tecnologias
- Java 

## Funcionalidades
- Registro de vendas
- - Registro de clientes
- Controle de estoque (entrada/saída)
- Relatórios básicos


## Como rodar
1. Clone o repositório
2. Execute a classe Main
